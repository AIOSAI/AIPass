# Shared skills

This folder is the one source for the skills both CLIs read. Codex scans `.agents/skills/` natively; Claude Code reads `.claude/skills/`, which is a symlink to this folder. A skill is a folder holding `SKILL.md` with `name` and `description` in its frontmatter, invoked as `/name` in Claude Code and `$name` in Codex. Add a shared skill here, never under `.claude/commands/`. Keep the frontmatter to the portable fields of the Agent Skills standard (`name`, `description`, `license`, `compatibility`, `metadata`, `allowed-tools`); a Claude-only field makes the file unusable elsewhere. Codex has no `$ARGUMENTS`: write "the words after the command" and both CLIs understand it. Skills that only make sense on one CLI stay in that CLI's folder: the switch to Codex lives in `.claude/commands/codex.md`, the switch back in `.codex/skills/claude/`.
