# Docs

Tracked public reference for the `SPAWN` branch: one page per module or handler group, in the shape `drone @seedgo standard docs_page` shows. Drafts and research go in `docs.local/`, which is untracked.

- [birth.md](birth.md) — citizen classes, the mint pipeline, the birth receipt and budget contract, adoption, the Python API
- [update_engine.md](update_engine.md) — the template walk, `.updateignore`, markdown drift, the list policy, the passport heal
- [registry_and_repair.md](registry_and_repair.md) — registry shapes, sync and fix, passport migration, seeds, regeneration, repair, the admin ceremony
- [retire.md](retire.md) — archive then deregister, and the three protection layers
- [cli_contract.md](cli_contract.md) — exit codes, introspection, the class-registry door and the docs page skeleton door
- [tests_and_quality.md](tests_and_quality.md) — what each test file pins, and the command behind every number
