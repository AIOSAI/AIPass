# Docs

Tracked public reference for the `{{BRANCHNAME}}` branch.

**The convention:** one file per module or handler group, named after it, each under
20,000 chars, and every one indexed from the branch README. This is where depth goes
when it outgrows the README — architecture notes, setup guides, policy write-ups —
so the README can stay the short face a stranger reads and the prompt can stay
breadcrumbs.

It is committed, so write it as if it ships. Work in progress, research and dated
one-offs belong in `docs.local/` instead, which is untracked.
