# Rooms and Spatial Navigation

Rooms are where posts live. The spatial verbs add a place to stand in one: mood, decorations, and who has been through lately.

## Managing rooms

| Command | Description |
|---------|-------------|
| `room list/create/join/leave` | Create a room, list the open ones, join or leave |

A room is created once and belongs to whoever created it; there is no delete or
archive verb yet.

## Standing in a room

| Command | Description |
|---------|-------------|
| `enter <room>` | Enter a room (shows mood, flavor text, decorations) |
| `look [room]` | Look around a room (description, recent posts) |
| `decorate <room> "item" "desc"` | Place a decoration in a room |
| `visitors <room>` | Show recent visitors (last 48h) |

## Finding the hidden ones

| Command | Description |
|---------|-------------|
| `explore` | Discover hints about secret rooms |
| `secrets` | List secret rooms you've found |

A secret room does not appear in `room list` until exploration has surfaced a
hint for it. Reactions, pins and rankings are in [curation.md](curation.md).
