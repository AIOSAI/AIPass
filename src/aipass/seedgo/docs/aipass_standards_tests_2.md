# aipass_standards — the test-file rows, module_scope_side_effect to weak_oracle

The second half of the pack's `tests` rows. They live on their own page because
[aipass_standards.md](aipass_standards.md) and these rows together exceed the docs-page size cap.
The columns read as the main page's

## The rows

| Standard | Scope | Applies to | What It Checks |
|----------|-------|-----------|----------------|
| module_scope_side_effect *(tests; signal_disposition everywhere)* | all_files | everywhere | A side effect that runs when a `test_*.py` is IMPORTED — top-level statements, class bodies, decorators, default arguments (not function bodies, not under `__main__`): `sys.addaudithook`, a host read (`Path.home()`, `expanduser`, `getcwd`), a write to `os.environ` / `sys.modules` / `sys.path`, a setattr on an import, `os.chdir`, a global recorder. `conftest.py` is exempt — the declared session harness (template C0). `signal_disposition` — `signal.signal` / `alarm` / `setitimer` at module scope — is judged in every file, production and conftest included: an imported module's top level runs in the pytest worker (specimen: CI 38132534544). The eight test shapes need a `test_*.py` in a tests tree, not the name alone — a product file named `test_token.py` under `apps/` gets the ninth only |
| mock_console *(tests only)* | all_files | tests | A console stand-in INSTALLED OVER the product, or handed to it — test template v1 item 14. Four install sites (`patch("...console")`, `patch.object`, `setattr`, `mod.console = X`) and one hand-off (`f(console=X)`); three stand-ins (a Mock — including the default MagicMock a bare `patch` supplies — a `Console(file=buf)`, a test-local fake with a `print` method). `capsys`, a console the PRODUCT builds, a restore, and a Mock for anything not console-named are never convicted. A `Console(file=...)` the test prints to ITSELF and never installs is counted in the passing message, never charged |
| named_encoding *(tests only)* | all_files | tests | A text read or write with no encoding named — `open()` in a text mode, `read_text()`, `write_text()` — test template v1 item 21. Binary modes, a positional encoding, and a deliberate non-utf-8 encoding (counted in the passing message) are never convicted. Scored per test file; also convicts in the checklist lane on the write |
| no_product_call *(tests only)* | all_files | tests | A `def test_*` that reaches NO aipass code: a LIBRARY test. A REACHABILITY rule, not a call-site rule: the body, the decorators, every same-file helper called and every fixture requested. Naming the product means an `aipass.*` import binding, a module-level constant that reaches one (to a fixed point, which is how a parametrized test reaches `mod.handle_command`), a dotted `"aipass...."` string, a multi-line literal mentioning aipass (a probe source), or a path from `__file__`. Two acquittals: a call into the file's OWN apparatus (a same-file helper or a conftest fixture — a control for an in-file detector is a meta-test), and a method of a class whose body reaches (a `TestCase` reaches through `self.conn`, which `setUp` built) |
| oversize_test_file *(tests only)* | all_files | tests | A test file over 1,500 CODE lines — multi-line string payload, docstrings included, is subtracted first. Scored per test file; also convicts in the checklist lane on the write |
| rendered_path_oracle *(tests only; ADVISORY)* | all_files | tests | A whole PATH, spelled in an f-string, asserted against output a console RENDERED — green on Linux, red on Windows and macOS (specimen: PR #787). Two fragilities: WRAP (Rich wraps at the console width, and a Windows or macOS tmp path crosses it) and REPR (`str(OSError)` renders the filename with `%r`, doubling Windows backslashes, which no console width cures). NEEDLE: an f-string rendering `tmp_path`, a name bound to it / `tmp_path_factory.mktemp()` / an expression rooted at one, a `Path(...)`-built name, `str(<path>)` or `<path>.parent`. HAYSTACK: `capsys`/`capfd.readouterr()` (tuple unpack, `.out`/`.err`, a bound capture), or `.output`/`.stdout`/`.stderr` of a CliRunner `invoke` or `subprocess.run`. `in`, `not in`, `==`, `!=`. `{path.name}` / `.stem` / `.suffix` is the cure and never convicts; a path compared against `str(exc)` or a returned value is acquitted. Not judged: an f-string bound to a name first, a transformed haystack. ADVISORY: scored per file, kept out of the gating average |
| retired_token_docstring *(tests only)* | all_files | tests | Cargo from the retired v4 keyword auditor (`test_quality`, c1e0eeed) in a test docstring: a run of its terms followed by `token(s)`, or a run of 2+ code-shaped terms (`capsys, capfd, StringIO`). The vocabulary is v4's own `STANDARD_CATEGORIES`, verbatim, the union of c1e0eeed^ and 7cd59aa4^ (where `returns_dict` / `json_type` left it); backticked code is not judged |
| router_assert *(tests only)* | all_files | tests | A test whose every assertion is a command router returning `is True` — `is False` is never convicted. Scored per test file; also convicts in the checklist lane on the write |
| self_set_assert *(tests only)* | all_files | tests | A test that writes a value and then asserts the value is there. `r.files_deleted = 5` then `assert r.files_deleted == 5` is a statement about Python's `setattr`, and it passes with the product deleted. Three shapes, and the CONSTRUCTOR KWARG (`obj = C(attr=X)` then `assert obj.attr == X`) is the one nobody sees while writing it. THE JUDGEMENT: score only when NOTHING RAN in between. A call between the write and the read makes the assert a durability oracle — "the product did not clobber this" — which is a real claim, and those ride in the passing message as a count. The comparison must also be `==` against the SAME literal: `client._drive_service = service` then `assert client.drive_service is service` sets the backing field and asserts the PROPERTY, so the getter is under test and the rule declines it. `weak_oracle` reads a self-set assert as STRONG because it is a real value comparison; this rule is the other half of that verdict |
| sleep_in_test *(tests only)* | all_files | tests | `sleep` inside a test — test template v1 item 23. Every hit is scored: both shapes have a strictly better cure. A sleep to move an mtime is a 0.01s nudge that does not move it at all on a one-second-granularity filesystem, where `os.utime(path, (when, when))` sets it exactly and instantly; a sleep to wait for something is a bet the machine is fast enough today, where a deadline poll on the REAL condition is faster and honest. Matched by the call's TAIL name, because the module is spelled many ways (`time`, `_time`, `time_module`, `time_mod`) and matching `time.sleep` alone misses them |
| stale_header_date *(tests only)* | all_files | tests | A `# Modified:` date older than the file's last commit (an uncommitted file is judged as of today). The first checker to READ GIT, read-only; it DECLINES (not applicable, out of the average) with no git, no work tree or a shallow clone — CI's audit job keeps `fetch-depth: 0` |
| state_leak *(tests only)* | all_files | tests | A write to shared state at TEST TIME with nothing to put it back — test template v1 item 18. Four shapes: a direct write (`os.environ[k] = v`, `sys.path.insert`, `sys.modules[k] = v`, `mod.attr = x` / `setattr(mod, ...)` on an imported product module), a patcher `.start()`ed and never stopped, and `os.chdir` with no restore, and a call to a product function that writes a module-level container the product's own public `reset*` writes, with no autouse fixture in the file or any `conftest.py`, no requested fixture and no `finally` calling that reset (a test that only reads the state is a stated miss). Every `monkeypatch` verb credits its own family only; `with patch(...)`, `@patch`, a `try`/`finally`, and a restoring fixture the test REQUESTS are never convicted, nor is a `sys.modules` key naming an aipass module (`import_site` owns it). Depth ONE only — `mod.helper.return_value = x` configures an object, not the module. A write at import time is counted in the passing message, never charged |
| stdlib_patch *(tests only)* | all_files | tests | A `patch`, `patch.object` or `monkeypatch.setattr` whose target resolves to a stdlib module rather than aipass. Replacing `os.path.getsize` or `shutil.copy2` is process-wide, so the test pins the product's SPELLING, not its behaviour. The target is resolved through the FILE'S OWN IMPORTS, not read off the local alias: `patch.object(ceiling.os.path, ...)` resolves to `aipass.backup...ceiling.os.path`, and the boundary is the first segment that is no longer a product module ON DISK. That disk check is the defence against a name collision — a branch's own `modules/email.py` is not stdlib `email`, and guessing from the name would convict it. A stdlib CLASS reached through a product binding is judged by what it IS, not by which name reached it: `monkeypatch.setattr(upload.Path, "resolve", ...)` is looked up in `upload.py`'s own imports and lands on `pathlib`, the same verdict `patch("pathlib.Path.resolve")` gets, while a class the module DEFINES (`agent.TranscriptScanner`) stays acquitted. A relative import keeps its leading dots, so `from ..json import json_handler` is a sibling package and never stdlib `json`. ACQUITTED as seams a test is right to seal: the process edges (`subprocess`, `socket`, `urllib`, `http`, `smtplib`, `ssl`, `ftplib`, `asyncio`, `select`) and the interpreter's own tables (`sys.argv`, `sys.stdout`, `sys.stderr`, `sys.stdin`, `sys.path`, `sys.modules`, `os.environ`). Reported with a count and charged to nobody: a target bound to a LOCAL name by assignment, which the AST cannot resolve |
| subprocess_text_true *(tests only)* | all_files | tests | A `subprocess` call (`run`, `Popen`, `check_output`, `check_call`, `call`) with literal `text=True` or `universal_newlines=True` and no `encoding=` — the locale codec decodes the child's output (cp1252 on Windows): `named_encoding`'s hazard one pipe over. `encoding=None` still convicts; `errors=` alone does not cure |
| through_the_command *(tests only)* | all_files | tests | A test importing an underscore name from a product module, or reaching one on a base it imported — test template v1 item 10. Dunders, the test's own helpers, reads on returned values, and WRITES (item 15's shape) are never convicted. Scored per test file; also convicts in the checklist lane on the write |
| uncalled_public_function *(tests only)* | branch_level | tests | A public function of a test file's DECLARED SUBJECT module — the path in its one-line docstring, template item 6 — that no test in the branch calls. Named in a `Call`, or an attribute access that is then called, IS called; named ONLY as a `patch`/`monkeypatch.setattr` target is **O1 replaced, never run**; named nowhere and unreachable is **O2**. The false conviction to avoid is a function the product still reaches: a name-level call graph over the branch's `apps/`, seeded with every function the tests do call and closed to a fixed point, acquits it, and the count rides in the passing message. Reads the docstring with `findall`, because a subject line can name two modules. Only a test file that declares a subject is judged; `file_top`'s item 6 convicts the rest |
| unconsumed_side_effect *(tests only)* | all_files | tests | `mock.side_effect = [more than one answer]` in a test that never claims how many times the mock was called. A list of three says the product will call the mock three times; nothing in the test says so, and if it calls twice the third answer is never consumed, the test still passes, and the branch that answer was written to feed is deletable with the suite green. ACQUITTED by any claim on the calls: `call_count`, `assert_called*`, `assert_has_calls`, `mock_calls`, `call_args`, `assert_not_called`, the `await_` forms. SCORED when the mock reaches no assertion at all. COUNTED when the mock is asserted some other way (its return value reaches an assert), because the shape is legitimate. A list of ONE is never judged — a single queued answer is a return value spelled differently, with no tail to lose. The cure is one line: `assert mock.call_count == 3` |
| unused_conftest_fixture *(tests only)* | branch_level | tests | A fixture defined in a branch's `conftest.py`, not `autouse`, that nothing in its `tests/` tree ever requests. Branch-level and not folded into `conftest_fixtures`, because "is this requested" is a fact about the whole tree and an `all_files` rule reading its siblings would be a file-level rule in disguise. A request counts in every spelling: a parameter on a test OR on another fixture (so a chain's root is never convicted), and any string literal in the tree, which covers `usefixtures` and `getfixturevalue` without reading only those two call shapes. `autouse=True` means nothing needs to ask, and is never convicted |
| weak_oracle *(tests only)* | all_files | tests | A test whose WHOLE oracle cannot fail. Scored on the six forms that cannot be right when they are the only assertions: `assert <constant>`; a bare NAME's truthiness (never a call's — `assert is_ignored(p, spec)` is the claim); `is not None` alone; `isinstance` alone; `assert_called`/`assert_called_once` with no argument check; and `assert f(...) is None` where `f` is annotated `-> None`, resolved through a module alias as well as a direct import. Reported with a count and charged to nobody: plain `is None`, `len`/`count` compares, bounds, `in`/`not in`, `== {}`. A `pytest.raises` acquits outright; a SOFT companion does not, only a strong one does. `router_assert`'s `is True` reads as strong, so the two never meet |
